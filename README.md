# Confidence signals and deferral in retinal OCT

MSc project, UCL AI for Biomedicine and Healthcare.

**Research question:** Under dataset shift in retinal OCT, does a deferral policy learned over several confidence signals outperform its individual components and a cost-optimised threshold on softmax confidence?

An EfficientNetV2-B0 classifier provides four-class predictions. Deferral policies use OOD scores, stochastic uncertainty, conformal set size, or their combination. Evaluation covers Kermany test, three RETOUCH vendors, RASTI, NEH and three OCTDL tiers.

## Method

- Fixed Kermany splits: 70,484 training, 5,000 validation, 8,000 calibration and 968 test images; seed 42.
- Backbone: ImageNet initialisation, 260 x 260 inputs, no augmentation; checkpoint selected by validation macro-F1.
- OOD signals: maximum cosine similarity and an equal-weight ensemble of six standardised negative squared Mahalanobis scores. Detectors are fitted on training features.
- Uncertainty: mutual information over 50 stochastic passes. Randomness comes from DropPath; BatchNorm and classifier dropout remain in evaluation mode.
- Conformal prediction: Mondrian sets at alpha = 0.02. The global and alpha-sweep outputs are supplementary diagnostics.
- Deferral: sigmoid expected-cost fitting with L2 regularisation on calibration data. The selected error-to-deferral cost ratio is 20:1, based on validation results. All parameters are frozen for external evaluation.

| Condition | Signals or rule |
| --- | --- |
| 1 | Accept all predictions |
| 2 | Cosine and Mahalanobis scores |
| 3 | Mutual information |
| 4 | Conformal set size |
| 5 | All signals from conditions 2-4 |
| B2 | Cost-optimised softmax threshold |

**AUGRC is the primary full-range metric.** Matched coverage at 0.70, 0.80 and 0.90 and each policy's fitted operating point provide complementary comparisons. AURC, confusion matrices, source-separation AUROC and other diagnostics are retained as supplementary results.

Classification errors are used for labelled sources. RETOUCH and the OCTDL ambiguous and novel-class tiers use predictions of NORMAL as missed-disease errors. Comparisons are made within sources. Zero-error sources are excluded from mean ranks.

The recorded AURC/AUGRC curves average outcomes within tied scores. Matched-coverage tables retain the original sort-order and 101-point interpolation convention. The 0.70-0.90 window metric is divided by the window width.

## Environment and data

The experiment used Python 3.12.13 on an Apple M4 Pro with MPS. Scripts select CUDA, MPS or CPU automatically. Set `OCT_DEVICE=cpu` to force CPU execution. Cached-score evaluation runs on CPU.

```bash
python -m pip install -r requirements.txt
```

Run commands from this repository's root. Data default to the sibling `Dataset/` directory. To use another location:

```bash
export OCT_DATA_ROOT="/path/to/Dataset"
```

Expected dataset directories beneath that root:

| Dataset | Directory |
| --- | --- |
| Kermany | `Paul_Mooney/OCT2017/` |
| RETOUCH | `RETOUCH/RETOUCH/` |
| RASTI | `Macular-Dataset-R.Rasti_old/` |
| NEH | `Tehran_Labeled Retinal Optical Coherence Tomography Dataset for Classification of Normal, Drusen, and CNV Cases/` |
| OCTDL | `OCTDL Optical Coherence Tomography Dataset for Image-Based Deep Learning Methods/` |

**RASTI is called OCT5k in earlier scripts, cache keys and saved outputs. These names refer to the same dataset.** Existing names are retained for compatibility.

Split paths are relative to the dataset root. The CSV loader also resolves recorded absolute image paths containing `/Dataset/`. It preserves row order. Source images are read-only.

## Run order

The supplied splits are fixed. Step 02 documents their construction and refuses to overwrite existing split CSVs. Step 03 resumes if `checkpoints/last.pt` exists.

| Stage | Scripts, in order |
| --- | --- |
| Initial checks | `00_benchmark` (optional), `00b_inspect_ood_data`, `00c_retouch_bitdepth`, `01_count_data` |
| Backbone and signals | `03_train_backbone`, `04_extract_features`, `05_ood_detection`, `06_conformal`, `06b_compare_schemes`, `07_policy` |
| RETOUCH and RASTI | `08a_extract_ood_features`, `08b_score_ood`, `08c_evaluate` |
| Additional datasets | `11_explore_new_data`, `12_data_integrity_checks`, `13a_extract_new_ood_features`, `13b_score_new_ood` |
| Combined evaluation | `13c_evaluate_all_sources`, `14_cost_and_coverage`, `15_augrc`, `15b_plot_grc`, `16_verify_dataset_counts`, `17_confusion_by_disease`, `18_thesis_tables` |

Run each entry as `python src/<script>.py`. Additional plots are generated by `03b_plot_training`, `04b_plot_features` and `05b_plot_ood` after their corresponding main steps. `09_aurc` produces the initial-source supplementary AURC table and supplies curve functions used later.

With the supplied tables, frozen parameters and four small probability arrays, reproduce the final evaluation without raw images or feature extraction:

```bash
python src/13c_evaluate_all_sources.py
python src/14_cost_and_coverage.py
python src/15_augrc.py
python src/15b_plot_grc.py
python src/17_confusion_by_disease.py
python src/18_thesis_tables.py
```

To regenerate only the thesis tables from existing evaluation tables, run the final command alone.

Scripts overwrite their corresponding outputs inside this repository. Reproducing feature extraction requires `checkpoints/best.pt` and the datasets; downstream scoring requires the cached arrays. Fresh training or stochastic inference may produce different values.

## Files

- `src/`: numbered scripts and the shared path helper.
- `splits/`: fixed sample indices.
- `cache/`: feature arrays, image indices and frozen detector, conformal and policy parameters.
- `checkpoints/`: best model and resumable training state.
- `results/tables/`: numeric results and diagnostic reports. `18_T20` to `18_T24` are the final thesis tables.
- `results/figures/`: all existing figures, including confusion matrices.

The code-and-results ZIP includes source, figures, tables, splits, frozen scoring parameters, image indices and the four probability arrays required by step 14 (`test`, `oct5k`, `neh`, `octdl`). It supports the evaluation commands above. Raw images, feature arrays, stochastic-pass arrays and checkpoints are not included. Full retraining requires the datasets and an initial ImageNet weight download; regenerating signals from the trained model requires `best.pt`.

The full local working copy retains all caches and checkpoints. `.gitignore` excludes the large arrays and checkpoints from Git, while retaining the small evaluation arrays.
